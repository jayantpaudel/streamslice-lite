StreamSlice Lite

Rust engine · no GPU required · one render at a time

1 · Prepare this PC

Checking helpers…

First setup downloads about 200 MB of pinned, SHA-256-verified FFmpeg and portable Streamlink files. No admin, Rust compiler, separate Python installation or system PATH changes are needed. Their upstream licenses remain in the helper distributions.

2 · Source

Best keeps maximum available source detail. A source-only channel may not offer lower variants. Local-file mode simulates a live feed, not full-file batch analysis.
Up to ~3 minutes are buffered on disk, less at high bitrates. A 256 MiB buffer safety stop protects storage. Starting again clears temporary video, never exports.

3 · Quality-first export

Quality uses Lanczos scaling, H.264/AAC, normalized audio and one background CPU thread. It takes longer on an old i3. Upscaling cannot create missing detail. Copy preserves original quality but cut/caption timing can vary by a keyframe.

Optional cloud AI

The model analyzes sampled speech, not video. It can miss gameplay/quiet moments. Review every cut, name, caption and frame before posting.
